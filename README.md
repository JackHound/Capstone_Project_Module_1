# Capstone_Project_Module_1
This project is Based on Case Study from Purwadhika, Data Science and Machine Learning Class

## Library Management System
For starters, this project is basically done with python basic function. The goal of this capstone project is:
1. Make sure that i, as student, have **strong understanding about basic Python**.
2. Build a basic **Library Management System** where the users are able to **perform various task**.
3. Push **critical thinking**. We as a developer need to know what happen to 'this code' where user choose 'this option' or maybe what happen when user choose 'that option'
4. Build a system based on the **flow chart reference and adapt along the way**.

## What can you do in this system?
This system has various features depends on your role. As an Admin or as a member. For example, as an admin, you can:
1. **Delete** books data
2. **Add** books data (Based on Member Request)
3. **Update** books data
4. **Restore** deleted books
5. **Find** books
6. etc

While as a Member, you can perform something like:
1. **See all books** data
2. **Search** books
3. **Sort** books
4. Make a **request**
5. **Borrow**
6. **Return**
7. **Update** biodata
8. etc
